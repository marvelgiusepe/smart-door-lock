# 🔐 Smart Door Lock

An RFID-based smart door lock prototype developed as a school technology project.

## 📌 About The Project

This project is a prototype of an automatic door locking system that uses an RFID card/tag to control access to a door.

The system is designed to identify an authorized RFID card and control a servo motor to lock or unlock the door.

## ⚙️ Features

* RFID-based access control
* Automatic door lock/unlock
* Servo motor control
* LCD display for system information
* Sensor-based object/person detection
* Microcontroller-based system

## 🛠️ Hardware

* ESP32 / Arduino
* RFID RC522
* Servo Motor SG90
* LCD I2C
* IR Sensor
* LED
* Jumper wires and supporting components

## 💻 Technologies

* Arduino IDE
* C/C++ for Arduino
* ESP32
* RFID
* I2C
* Basic database and web integration

## 🔄 System Flow

```text
RFID Card/Tag
      ↓
RFID RC522
      ↓
Microcontroller
      ↓
Check Access
   ↙       ↘
Authorized  Unauthorized
   ↓            ↓
Unlock       Access Denied
   ↓
Servo Motor
```
